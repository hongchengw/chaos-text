# Chaos Text

Chaos Text is a joke typing toy: every character you type gets a random font, color, rotation, and scale, re-rolled for the whole line on every keystroke. The characters keep wobbling.

## Try it

Clone the repo and open `src/index.html` in your browser:

```
git clone https://github.com/hongchengw/chaos-text.git
cd chaos-text
```

Then double-click `src/index.html`, or serve it:

```
npx http-server
```

and visit `http://localhost:8080/src/index.html`.
